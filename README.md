# GuptaAman777 — Liquid Glass Portfolio & Scanlation Hub

The official personal portfolio, open-source project showcase, and scanlation reader for **@GuptaAman777**, built with an interactive **Liquid Glass** design system (`backdrop-filter`, specular refraction rims, dynamic ambient mesh, and Dark/Frost theme toggle).

## Featured Projects
- **[ImageTool (PSD & Image Converter Suite)](https://github.com/GuptaAman777/psd-converter)** — Python / PyQt6 desktop suite with Vulkan NCNN AI upscaling (`Real-ESRGAN`, `Real-CUGAN`, `Waifu2x`, `SRMD`), multi-engine denoising, PSD layer extraction, multi-page PDF rasterization, and high-capacity canvas stitching.
- **[File Renaming Tool](https://github.com/GuptaAman777/Rename-Tool)** — Smart regex-powered batch file renamer with auto-numbering, prefixes/suffixes, and instant undo.
- **[Image Stitcher](https://github.com/GuptaAman777/stitched)** — Standalone PyQt6 batch image stitcher and converter.
- **[GuptaAman777 Image Hosting](https://github.com/GuptaAman777/guptaaman777-imagehosting)** — Static media & chapter asset repository.
- **Scanlation Catalog & Reader** — Dynamic JSON-backed comic catalog (`details.html`) and vertical strip chapter reader (`reader.html`).
